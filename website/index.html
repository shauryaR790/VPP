V++

From the V++ project

V++ (vpp) is an open-source programming language and compiler. It aims for readable syntax, static typing with local inference, and native compilation via LLVM.

The compiler is written in Rust. Programs can run through a tree-walking interpreter or compile to native executables. The language includes structs, enums, generics, traits, Option/Result, modules, and v1.0.4 automation APIs (typed process I/O, env, directories, logging).
